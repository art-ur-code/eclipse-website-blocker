Eclipse - 网站屏蔽器不只是屏蔽让你分心的网站。它会让你在访问之前停下来、想一想，并对自己诚实。

🚫 把任何让你分心的网站加入屏蔽列表。当你试图打开它时，Eclipse 会用一个全屏暂停界面拦住你，并要求你：

• 说明你为什么现在需要访问这个网站
• 写满最少字符数，确保你的理由是深思熟虑的，而不只是一时冲动
• 选择允许自己停留多久（5–60 分钟）
• 确认你是在做出有意识的选择

实时字符计数器会显示你的进度，写够字数后会变成绿色。粘贴功能已被禁用，所以理由必须由你亲手输入，不能复制。

解锁网站后，页面底部会固定显示一条简洁的提醒栏，展示你的理由和实时倒计时。时间一到，网站就会自动重新屏蔽。你也可以随时点击“停止”，提前结束本次使用。

✨ Eclipse 为什么有效

• 增加阻力，而不是筑起高墙 — 真正需要时仍可访问网站，同时打断那些无意识的习惯性访问
• 让你说清自己的意图 — 写下真实的理由会迫使你停下来思考，而且无法粘贴，没有捷径可走
• 让你对自己负责 — 你在网站上时，理由始终可见
• 为使用时间设限 — 设定时限，让“就看五分钟”不会悄悄变成一小时
• 一键屏蔽 — 在任意网站上打开扩展弹窗，点击“屏蔽”按钮即可立即屏蔽
• 可自定义最少字数 — 自行设定解锁理由至少需要多少个字符（默认 50）
• 支持 11 种语言 — 英语、西班牙语、葡萄牙语（葡萄牙和巴西）、法语、德语、意大利语、俄语、简体中文、日语和印地语。Eclipse 默认跟随浏览器语言，你也可以在“设置”中选择其他语言
• 简洁清晰的弹窗 — 用于快速屏蔽的主页、独立的“已屏蔽的网站”列表，以及“设置”页面
• 同步屏蔽列表 — 已屏蔽的网站会在你已登录的各个 Chrome 浏览器之间同步
• 注重隐私 — 无需账号，没有跟踪，没有广告。你的数据只保存在 Chrome 的本地存储和同步存储中

🎯 非常适合想减少花在社交媒体、新闻、YouTube 或其他分心网站上的时间，同时又希望在真正需要时能有意识地访问它们的人。

使用方法：

1. 打开一个让你分心的网站，点击 Eclipse 图标，然后点击“屏蔽”——或在“已屏蔽的网站”中手动添加网站
2. 尝试访问一个已屏蔽的网站
3. 输入你的理由，达到最少字符数要求
4. 选择时间限制并解锁网站
5. 借助提醒栏和倒计时对自己负责
6. 随时可以提前停止，或在时间结束时让 Eclipse 自动屏蔽该网站

每次分心之前，先用 Eclipse 停下来想一想。
